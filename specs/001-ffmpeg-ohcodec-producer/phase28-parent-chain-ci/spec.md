日期：2026-10-23（Asia/Shanghai）。承接已独立审查通过的 resume-04 R1/R2/F1，仅补齐独立远端宿主 CI。

## 用户授权与边界

先整理精确本地提交和推送预览，用户批准该 SHA 后才能推送/触发 CI。当前没有新 SHA 的远端写入批准。Player、TV 全目录只读；不替换候选库/HAR/default SDK；仅应用保屏、不改系统设置。本任务不操作设备。formalArtifactAllowed=false。

## 验收要求

- C001 固定完整源文件子集和原路径/SHA、测试、许可证；启动和结束核对输入全集，新增未知输入也拒绝。
- C002 实际编译父级链 RED 5/5 和 GREEN 12/12，编译失败不能充当 RED。
- C003 单独改动真实 uninit 的 queue 销毁顺序，再运行完整 GREEN；要求常规 late-unsafe 被实际门禁拒绝及总进程非零，不能只凭负例自报 PASS。
- C004 同一 FFmpeg 精确源码执行无诊断宏/诊断宏回调重放各 8/8。
- C005 清理门禁使用明确标注的合成记录，覆盖 timeout、Offline、失败、缺失与残留窗口/Ability。无设备连接、原始私人日志或新真机验收。
- C006 宿主工具版本、当前 Git SHA、子进程退出、失败日志、结果及上传索引必须留存；上传限 UTF-8 JSON/log，不含二进制和符号链接。
- C007 推送预览列出精确 SHA、parent、目的分支、全部文件及大小、触发条件、权限、允许上传范围、本地重放和未覆盖项；新 SHA 必须重新批准。
